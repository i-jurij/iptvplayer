# IPTV Player

**Версия:** 1.0.0

## Назначение

IPTV Player — это кросс-платформенное приложение для просмотра IPTV-каналов с поддержкой M3U-плейлистов, избранных каналов, логотипов и электронной программы передач (EPG).

Приложение предназначено для:

- Загрузки и управления M3U-плейлистами (локальными файлами и по URL).
- Просмотра и организации телеканалов в виде списка или карточек (сетка).
- Поддержки избранных каналов (сохранение и синхронизация).
- Автоматического и ручного обновления плейлистов в фоне без блокировки UI.
- Отображения логотипов каналов (асинхронная загрузка, кэширование на диске и в памяти).
- **Электронной программы передач (EPG)** с поддержкой нескольких XMLTV-источников, кэшированием и автообновлением.
- **Записи видео** (прямая запись воспроизводимого потока с возможностью выбора метода: `stream-record` или `record-file`).
- **Добавления плейлистов из репозитория IPTV-Org** с фильтрацией по странам, языкам и категориям.

## Программа передач (EPG)

### Что такое EPG

EPG (Electronic Program Guide) — это расписание телепрограмм, которое показывает, что идёт на каждом канале в данный момент, а также в прошлом и будущем.

### Как это работает в приложении

1. **Источники EPG** — вы добавляете один или несколько URL-адресов, указывающих на файлы в формате XMLTV (например, `guide.xml`). Приложение загружает эти файлы, парсит их и сохраняет данные в локальный кэш.
2. **Сопоставление с каналами** — сопоставление происходит автоматически по полю `tvg-id` из M3U-плейлиста. Если `tvg-id` отсутствует, канал не получит программу.
3. **Отображение** — текущая программа отображается в колонке **Program** списка каналов и во всплывающей подсказке карточек (сетка). Для детального просмотра используйте вкладку **Program**.
4. **Кэширование** — данные сохраняются на диск, чтобы при следующем запуске приложение не загружало EPG заново. Кэш автоматически очищается от программ старше указанного количества дней (настраивается в настройках).
5. **Автообновление** — если включено, приложение периодически обновляет EPG в фоне (интервал настраивается).

### Настройка EPG

1. Откройте **Настройки** → вкладка **EPG**.
2. В разделе **EPG Sources** нажмите **Add** и введите URL источника, а также опциональное название.
3. Настройте параметры:
   - **Auto-update** — включите, чтобы EPG обновлялся автоматически.
   - **Update interval (hours)** — как часто обновлять (по умолчанию 24 часа).
   - **Days to keep in cache** — сколько дней программ хранить в кэше (по умолчанию 3 дня).
4. Нажмите **Refresh Now**, чтобы загрузить EPG немедленно.

### Рекомендуемые источники EPG

| Источник | URL | Описание |
| :--- | :--- | :--- |
| IPTV-org (глобальный) | `https://iptv-org.github.io/epg/guide.xml` | Основной источник, охватывает тысячи каналов. |
| epg.pw | `https://epg.pw/guide.xml` | Публичный EPG-сервис с поддержкой многих каналов. |
| Open EPG | `https://open-epg.com/guide.xml` | Альтернативный бесплатный EPG. |
| iptvx.one | `https://iptvx.one/` | One more |

Вы можете использовать несколько источников одновременно. При загрузке данные из разных источников объединяются.

### Использование EPG в интерфейсе

- **Вкладка Program** — на главной панели нажмите кнопку **Program**.
  - Слева — список каналов (с поиском). Выберите канал → справа отобразится его расписание на текущий день.
  - Навигация по дням: кнопки `<`, `>`, `Today`.
  - Нажмите на программу, чтобы увидеть подробное описание.
  - Кнопка **Refresh** — обновить EPG вручную.
  - Кнопка **Manage Sources** — открывает настройки EPG.

- **Контекстное меню каналов** — в списке или сетке каналов (вкладка Channels) вызовите контекстное меню (ПКМ) и выберите **Program Guide**. Произойдёт переход на вкладку Program с автоматическим выбором этого канала.

- **Колонка "Program" в списке** — показывает текущую программу для каждого канала (обновляется при загрузке EPG).

- **Tooltip в сетке** — при наведении на карточку канала во всплывающей подсказке отображается текущая программа.

## Запись видео

- Запись текущего воспроизводимого потока (поддерживаются методы `stream-record` и `record-file` — выбор в настройках).
- Кнопка **Rec** на панели управления видео; активна во время воспроизведения.
- Запись начинается с текущего момента, файл сохраняется в настраиваемый каталог.
- В статус-баре отображается имя файла и длительность записи.
- При остановке воспроизведения запись автоматически останавливается.

## Добавление плейлистов из IPTV-Org

- Через кнопку **"Add from IPTV-Org…"** на вкладке **Playlists**.
- Фильтр по странам, языкам или категориям с динамической загрузкой данных из официального репозитория.
- При выборе плейлист автоматически скачивается и добавляется в список.

## Интерфейс

- Вкладки: **Playlists** (управление плейлистами), **Channels** (каналы текущего плейлиста), **Favorites** (избранные каналы), **Video** (просмотр), **Program** (программа передач).
- Переключение между списком и сеткой для каналов и избранного.
- Поиск каналов (TypeAheadSearch) в списке и сетке.
- Контекстное меню для каналов (ПКМ): "Program Guide", "Copy URL".
- Полноэкранный режим видео (двойной клик, F или ESC).
- Управление громкостью, отключение звука, регулировка задержки аудио, переключение аудио/субтитров (в меню).

| Клавиша | Действие |
| :--- | :--- |
| `Space` | Play / Pause |
| `Left` / `Right` | Перемотка назад / вперёд (5 сек) |
| `Shift+Left` / `Shift+Right` | Перемотка назад / вперёд (30 сек) |
| `Ctrl+Left` / `Ctrl+Right` | Перемотка назад / вперёд (1 сек) |
| `Home` / `End` | Перейти в начало / конец |
| `Up` / `Down` | Увеличить / уменьшить громкость (5 шагов) |
| `Ctrl+Up` / `Ctrl+Down` | Громкость (1 шаг) |
| `m` / `M` | Включить / выключить звук |
| `[` / `]` | Уменьшить / увеличить скорость воспроизведения (0.1) |
| `{` / `}` | Уменьшить / увеличить скорость воспроизведения (0.5) |
| `Backspace` | Сбросить скорость до 1.0 |
| `+` / `_` | Следующая / предыдущая аудиодорожка |
| `v` / `V` | Включить / выключить субтитры |
| `j` / `J` | Следующая дорожка субтитров |
| `h` / `H` | Предыдущая дорожка субтитров |

| `q` / `Q` | Остановить воспроизведение |

## Структура данных

- Конфиг: `~/.config/iptvplayer/config.json`
- Плейлисты: `~/.config/iptvplayer/playlists/*.json`
- Избранное: `~/.config/iptvplayer/favorites.json`
- Кэш иконок: `~/.cache/iptvplayer/icons/`
- Кэш EPG: `~/.cache/iptvplayer/epg/epg_cache.json`
