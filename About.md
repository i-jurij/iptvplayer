# IPTV Player

## Назначение

Приложение предназначено для:

- Загрузки и управления **M3U-плейлистами** (локальными и по URL).
- Просмотра и организации **телеканалов**.
- Поддержки **избранных каналов**.
- Обновления плейлистов с автоматической загрузкой.
- Отображения логотипов каналов.

## Архитектура и компоненты

### Точка входа

- `main.cpp` → `wxIMPLEMENT_APP(Application)`.
- Класс `Application` (наследуется от `wxApp`) управляет жизненным циклом приложения.

### Основные классы

| Класс | Назначение |
| :--- | :--- |
| `Application` | Инициализация приложения, создание `GUIManager`, загрузка настроек и плейлистов. |
| `GUIManager` | Создание и управление главным окном (`MainFrame`). |
| `MainFrame` | Главное окно с вкладками: **Playlists**, **Channels**, **Favorites**, **Video**. Управляет навигацией и событиями. |
| `ConfigManager` | Работа с конфигурацией (JSON): сохранение/загрузка настроек (`config.json`). |
| `PlaylistManager` | Управление коллекцией плейлистов, загрузка/обновление, сохранение в `~/.config/iptvplayer/playlists/`. |
| `Playlist` | Хранение информации о плейлисте: название, источник, каналы, настройки обновления. |
| `Channel` | Модель канала: имя, URL, `tvg-logo`, `group-title`, язык, страна и т.д. |
| `M3UParser` | Парсинг M3U-файлов, извлечение каналов и атрибутов. |
| `IconManager` | Асинхронная загрузка и кэширование логотипов каналов (в WebP, PNG, SVG). Поддерживает LRU-кэш. |
| `FavoritesManager` | Управление избранными каналами (сохранение в `favorites.json`). |
| `ChannelList` / `ChannelCards` | Отображение каналов в виде списка или карточек. |
| `FavoritesCards` / `FavoritesList` | Отображение избранных каналов. |
| `UpdateOneThread` / `UpdateAllThread` | Многопоточное обновление отдельного или всех плейлистов. |

### Диалоги

- `AddPlaylistFileDialog` — добавление плейлиста из файла.
- `AddPlaylistUrlDialog` — добавление по URL.
- `EditPlaylistDialog` — редактирование с возможностью экспорта в M3U.
- `SettingsDialog` — настройки медиаплеера и автообновления.

## Структура данных

- Конфиг: `~/.config/iptvplayer/config.json`
- Плейлисты: `~/.config/iptvplayer/playlists/*.json`
- Избранное: `~/.config/iptvplayer/favorites.json`
- Кэш иконок: `~/.cache/iptvplayer/icons/`

## Технологии

- **C++20** (в `CMakeLists.txt`)
- **wxWidgets 3.3.2** (статическая сборка)
- **libcurl** — загрузка по URL
- **libwebp** — обработка WebP-изображений
- **rapidjson** — работа с JSON (в `FavoritesManager`)
- **CMake** — сборка

## Сборка и запуск

- Зависимости собираются локально (в `third_party/`).
- Скрипты: `setup-deps.sh`, `build-release.sh`.
- Генерируется `compile_commands.json` для IDE.

## Ключевые особенности

- Поддержка асинхронной загрузки иконок с кэшированием в памяти и на диске.
- Многопоточное обновление плейлистов без блокировки UI.
- Поддержка разных режимов отображения (список / карточки).
- Экспорт плейлиста в M3U.
- Поддержка DPI-адаптивного масштабирования интерфейса.
