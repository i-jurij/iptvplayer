IPTV Player

A IPTV player with M3U playlist support, favorites, channel logos, and an Electronic Program Guide (EPG).

Screenshots

Features

  • Playlist management: add local/remote M3U playlists, edit, update, remove.
  • Channel views: list or grid (cards) with sorting and search.
  • Favorites: mark channels, view separately.
  • EPG (Electronic Program Guide):
    • XMLTV sources configuration (Settings → EPG, or the Program tab);
    • auto-update interval and cache expiration;
    • program tab with day navigation and details;
    • quick jump from the channel context menu;
    • manual channel-to-EPG mapping.
  • Video playback: fullscreen, volume, mute, audio/subtitle tracks, speed control.
  • Recording: record the current stream to a user-defined directory.
  • IPTV-Org integration: add playlists from the public IPTV-Org repository with filters by country, language, and category.
  • Export: export any playlist to M3U.

Installation

All artifacts come with checksums.txt and a detached GPG signature. See SECURITY.md for verification instructions.

Codec for H.264 streams

Most IPTV streams are H.264. Some distributions do not include a decoder for it by default, and playback fails with a black screen or Unable to create decoder for h264.

  • Fedora / RHEL: sudo dnf install openh264.
  • Debian / Ubuntu: sudo apt install libopenh264-7. If the package is not found, try sudo apt install libavcodec-extra.
  • Arch / Manjaro: sudo pacman -S ffmpeg (H.264 decoding is included). Optionally also sudo pacman -S openh264.

Then restart the application.

First launch

  1. Add a playlist. Open the Playlists tab and use one of:
    • Add from file — local .m3u / .m3u8;
    • Add from URL — remote M3U;
    • Add from IPTV-Org — browse the public IPTV-Org repository.
  2. Open the playlist. Double-click it (or press Open) and switch to the Channels tab.
  3. Add an EPG source (optional). Open the Program tab (or Settings → EPG), press Add, and enter an XMLTV URL. Press Refresh Now to load it.
  4. Configure the rest (optional). In Settings you can enable channel logos, choose the recording method (stream-record or record-file), and adjust cache and auto-update intervals.

Usage

Playlists

The Playlists tab is where you manage your playlist collection. Each playlist has a title, source (local file or URL), and update settings. You can:

  • add, edit, update, and remove playlists;
  • manually update one playlist or all playlists at once (updates run in the background — the UI stays responsive);
  • export a playlist to a local .m3u file.

Channels

The Channels tab shows the channels of the currently opened playlist.

  • List or grid — switch between the two views with the toolbar buttons. Grid view shows channel cards with logos.
  • Filters — filter by group, country, and language; sort by name, group, or country.
  • Search — TypeAheadSearch in list and grid views.
  • Context menu (right click) — "Program Guide", "Copy URL", "Copy Name", "Remove from playlist".
  • EPG panel — the Channels tab has a vertical splitter with an EPG panel on the right that shows the schedule for the currently selected channel (see the EPG section below).

Favorites

The Favorites tab mirrors the Channels tab but only shows channels you have marked as favorite. Same list/grid views, same filters, same EPG panel. Favorites are stored separately and persist across playlist updates.

EPG

What it is. EPG (Electronic Program Guide) is a TV schedule that shows what is airing on each channel now, as well as what aired before and what will air later.

How it works in the app:

  1. Sources — you add one or more XMLTV URLs (guide.xml style). The app downloads them, parses them, and stores the data in a local SQLite cache.
  2. Matching — matching to your playlist channels happens automatically. First by the tvg-id field from the M3U; if that's missing, by normalized channel name with regional suffixes (HD, FHD, (US), (UK), etc.) stripped. The algorithm uses Jaro-Winkler, token comparison, and substring matching.
  3. Manual mapping — if automatic matching fails or is wrong, you can link a channel to an EPG channel by hand (see Manual EPG mapping below).
  4. Ignoring — you can mark an automatic mapping as Ignored so it is not used, without deleting it. Restore it later if needed.
  5. Display — the current program shows in the Program column of the list and in the tooltip on cards. For a detailed view, use the EPG panel on the Channels/Favorites tabs, or the Program tab to manage sources.
  6. Caching — data is saved to disk so the app does not re-download EPG on the next launch. Programs older than the configured number of days are cleaned out automatically.
  7. Auto-update — if enabled, EPG is refreshed in the background at a configurable interval. When refreshing, the app checks whether the playlist has changed (by hash); if not, mapping is not recomputed.

Setting up EPG:

  1. Open Settings → EPG, or switch to the Program tab.
  2. In EPG Sources, press Add and enter the source URL and an optional name.
  3. Configure:
    • Auto-update — enable to refresh automatically.
    • Update interval (hours) — default 24.
    • Days to keep in cache — default 3.
  4. Press Refresh Now to load EPG immediately.

Recommended sources. The file epg_sources.json in the resources directory (/usr/share/iptvplayer/resources/) contains links to the most well-known sources. Links change and go stale, so verify their availability online before relying on them. You can use multiple sources at once — data is merged on load.

EPG panel (Channels / Favorites tabs).

  • Selecting a channel shows its schedule for the current day on the right.
  • Day navigation: < (previous day), > (next day), Today (back to today).
  • Clicking a program opens a dialog with a detailed description (title, time, description, category).
  • Refresh button — force reloads EPG from all sources and re-matches channels.

Program tab.

  • A separate tab for administering EPG:
    • add / remove sources (URL and name);
    • enable / disable auto-update per source;
    • trigger a manual refresh of all sources (Refresh Now);
    • set global parameters: update interval, days to keep in cache.
  • This tab does not show channel schedules.

Manual EPG mapping

The Manual Mapping dialog lets you link a channel from the current playlist to a channel from the EPG.

How to open it:

  • From the channel context menu → Manual Mapping (if present in your build);
  • From the Manual Mapping button on the EPG control panel (Program tab or Settings).

Dialog features:

  • Left: playlist channels with search and sorting by name or tvg-id.
  • Right: EPG channels (from the DB) with search and sorting.
  • Add mapping → — creates a manual mapping for the selected pair.
  • Below: a table of all existing mappings for the current playlist (status: Auto, Manual, Ignored).
  • Remove mapping, Ignore, Unignore — manage the selected mapping.
  • A manual mapping takes priority over the automatic one for that key.

Note: manual mappings are stored in the database and persist across sessions. When a channel is removed from a playlist, its mapping is removed automatically (both by tvg-id and by normalized name).

Recording

  • Records the currently playing stream.
  • Two methods are supported — stream-record and record-file — chosen in Settings.
  • The Rec button on the video panel is active during playback.
  • Recording starts from the current moment; the file is saved to a configurable directory.
  • The status bar shows the file name and duration.
  • Stopping playback stops recording automatically.
  • .ts and .mkv containers are supported depending on the stream codec.

IPTV-Org

  • Button "Add from IPTV-Org…" on the Playlists tab.
  • Filter by country, language, or category, with dynamic data loading from the official IPTV-Org repository.
  • The playlist is downloaded and added to your collection automatically.

Export

  • In the playlist edit dialog, press Export.
  • Choose a path and file name — an M3U file with the channels of the selected playlist is created.

Interface

  • Tabs: Playlists (playlist management), Channels (channels of the current playlist), Favorites, Video (playback), Program (EPG source management).
  • Switch between list and grid for channels and favorites.
  • Channel search (TypeAheadSearch) in both views.
  • Channel context menu (right click): "Program Guide", "Copy URL", "Copy Name", "Remove from playlist".
  • Fullscreen video (double-click, F, or ESC).
  • Volume, mute, audio delay, audio/subtitle track switching (from the menu).

IPTV Player

Кросс-платформенное приложение для просмотра IPTV-каналов с поддержкой M3U-плейлистов, избранных каналов, логотипов и электронной программы передач (EPG).

Скриншоты

Возможности

  • Управление плейлистами: добавление локальных и удалённых M3U-плейлистов, редактирование, обновление, удаление.
  • Представления каналов: список или сетка (карточки) с сортировкой и поиском.
  • Избранное: отметить каналы, просматривать отдельно.
  • EPG (электронная программа передач):
    • настройка XMLTV-источников (Настройки → EPG или вкладка Program);
    • интервал автообновления и время жизни кэша;
    • вкладка программы с навигацией по дням и подробностями;
    • быстрый переход из контекстного меню канала;
    • ручное сопоставление каналов с EPG.
  • Воспроизведение видео: полноэкранный режим, громкость, mute, аудио/субтитры, скорость.
  • Запись: запись текущего потока в указанный каталог.
  • Интеграция с IPTV-Org: добавление плейлистов из публичного репозитория IPTV-Org с фильтрами по стране, языку и категории.
  • Экспорт: выгрузка любого плейлиста в M3U.

Кодек для потоков H.264

Большинство IPTV-потоков — H.264. В некоторых дистрибутивах декодер для него не входит в стандартную поставку, и воспроизведение падает с чёрным экраном или ошибкой Unable to create decoder for h264.

  • Fedora / RHEL: sudo dnf install openh264.
  • Debian / Ubuntu: sudo apt install libopenh264-7. Если пакет не найден, попробуйте sudo apt install libavcodec-extra.
  • Arch / Manjaro: sudo pacman -S ffmpeg (декодер H.264 уже входит). Дополнительно можно установить sudo pacman -S openh264.

После установки перезапустите приложение.

Первый запуск

  1. Добавьте плейлист. Откройте вкладку Playlists и используйте один из вариантов:
    • Add from file — локальный .m3u / .m3u8;
    • Add from URL — удалённый M3U;
    • Add from IPTV-Org — выбор из публичного репозитория IPTV-Org.
  2. Откройте плейлист. Двойной клик (или кнопка Open), затем перейдите на вкладку Channels.
  3. Добавьте EPG-источник (опционально). Вкладка Program (или Настройки → EPG), нажмите Add и введите URL XMLTV. Затем Refresh Now.
  4. Настройте остальное (опционально). В Настройках можно включить логотипы, выбрать метод записи (stream-record или record-file), настроить интервалы кэша и автообновления.

Использование

Плейлисты

Вкладка Playlists — управление коллекцией плейлистов. У каждого плейлиста есть название, источник (локальный файл или URL) и настройки обновления. Можно:

  • добавлять, редактировать, обновлять и удалять плейлисты;
  • обновлять вручную один плейлист или все сразу (обновления идут в фоне — UI остаётся отзывчивым);
  • экспортировать плейлист в локальный .m3u.

Каналы

Вкладка Channels показывает каналы текущего плейлиста.

  • Список или сетка — переключение кнопками тулбара. Сетка показывает карточки каналов с логотипами.
  • Фильтры — по группе, стране и языку; сортировка по имени, группе или стране.
  • Поиск — TypeAheadSearch в списке и сетке.
  • Контекстное меню (ПКМ) — "Program Guide", "Copy URL", "Copy Name", "Remove from playlist".
  • Панель EPG — на вкладке Channels есть вертикальный сплиттер с EPG-панелью справа, где показывается расписание выбранного канала (см. раздел EPG).

Избранное

Вкладка Favorites повторяет Channels, но показывает только отмеченные каналы. Те же виды (список/сетка), те же фильтры, та же панель EPG. Избранное хранится отдельно и не теряется при обновлении плейлистов.

EPG

Что это. EPG (Electronic Program Guide) — расписание телепрограмм, показывает что идёт сейчас, что шло раньше и что будет позже.

Как это работает в приложении:

  1. Источники — вы добавляете один или несколько XMLTV-URL (в стиле guide.xml). Приложение скачивает их, парсит и сохраняет в локальный кэш SQLite.
  2. Сопоставление — с каналами плейлиста автоматически. Сначала по полю tvg-id из M3U; если его нет — по нормализованному имени с удалением региональных суффиксов (HD, FHD, (US), (UK) и т.д.). Алгоритм использует Jaro-Winkler, токен-сравнение и субстроки.
  3. Ручное сопоставление — если автоматика не сработала или дала неверный результат, можно связать канал с EPG вручную (см. Ручное сопоставление EPG ниже).
  4. Игнорирование — можно пометить автоматический маппинг как Ignored, не удаляя его. Вернуть позже.
  5. Отображение — текущая программа видна в колонке Program списка и во всплывающей подсказке карточек. Для подробностей — панель EPG на Channels/Favorites или вкладка Program для управления источниками.
  6. Кэширование — данные сохраняются на диск, при следующем запуске заново не скачиваются. Программы старше указанного числа дней автоматически удаляются.
  7. Автообновление — если включено, EPG обновляется в фоне через настраиваемый интервал. При обновлении проверяется, изменился ли плейлист (по хэшу); если нет — маппинг не пересчитывается.

Настройка EPG:

  1. Откройте Настройки → EPG или вкладку Program.
  2. В разделе EPG Sources нажмите Add и введите URL источника и опциональное имя.
  3. Настройте:
    • Auto-update — включить автообновление.
    • Update interval (hours) — по умолчанию 24.
    • Days to keep in cache — по умолчанию 3.
  4. Нажмите Refresh Now, чтобы загрузить EPG немедленно.

Рекомендуемые источники. Файл epg_sources.json в каталоге ресурсов (/usr/share/iptvplayer/resources/) содержит ссылки на самые известные источники. Ссылки меняются и устаревают — проверяйте их актуальность в сети. Можно использовать несколько источников одновременно: данные объединяются при загрузке.

Панель EPG (вкладки Channels / Favorites).

  • Выбор канала показывает справа его расписание на текущий день.
  • Навигация по дням: < (предыдущий), > (следующий), Today (вернуться к сегодня).
  • Клик по программе открывает диалог с подробным описанием (название, время, описание, категория).
  • Кнопка Refresh — принудительно перезагружает EPG из всех источников и пересопоставляет каналы.

Вкладка Program.

  • Отдельная вкладка для администрирования EPG:
    • добавление / удаление источников (URL и имя);
    • включение / отключение автообновления для каждого источника;
    • ручное обновление всех источников (Refresh Now);
    • глобальные параметры: интервал обновления, число дней хранения кэша.
  • Расписание каналов на этой вкладке не показывается.

Ручное сопоставление EPG

Диалог Manual Mapping позволяет связать канал из текущего плейлиста с каналом из EPG вручную.

Как открыть:

  • Из контекстного меню канала → Manual Mapping (если доступно);
  • Кнопкой Manual Mapping на панели EPG (вкладка Program или Настройки).

Возможности диалога:

  • Слева: каналы плейлиста с поиском и сортировкой по имени или tvg-id.
  • Справа: EPG-каналы (из БД) с поиском и сортировкой.
  • Add mapping → — создать ручной маппинг для выбранной пары.
  • Ниже: таблица всех существующих маппингов текущего плейлиста (статус: Auto, Manual, Ignored).
  • Remove mapping, Ignore, Unignore — управление выбранным маппингом.
  • Ручной маппинг имеет приоритет над автоматическим для данного ключа.

Примечание: ручные маппинги хранятся в БД и сохраняются между сессиями. При удалении канала из плейлиста его маппинг удаляется автоматически (как по tvg-id, так и по нормализованному имени).

Запись

  • Запись текущего воспроизводимого потока.
  • Поддерживаются два метода — stream-record и record-file — выбор в Настройках.
  • Кнопка Rec на панели видео активна во время воспроизведения.
  • Запись начинается с текущего момента; файл сохраняется в настраиваемый каталог.
  • В статус-баре отображается имя файла и длительность записи.
  • Остановка воспроизведения автоматически останавливает запись.
  • Поддерживаются контейнеры .ts и .mkv в зависимости от кодека потока.

IPTV-Org

  • Кнопка "Add from IPTV-Org…" на вкладке Playlists.
  • Фильтр по стране, языку или категории с динамической загрузкой данных из официального репозитория IPTV-Org.
  • Плейлист скачивается и добавляется в коллекцию автоматически.

Экспорт

  • В диалоге редактирования плейлиста нажмите Export.
  • Выберите путь и имя файла — будет создан M3U-файл с каналами выбранного плейлиста.

Интерфейс

  • Вкладки: Playlists (управление плейлистами), Channels (каналы текущего плейлиста), Favorites (избранное), Video (воспроизведение), Program (управление источниками EPG).
  • Переключение между списком и сеткой для каналов и избранного.
  • Поиск каналов (TypeAheadSearch) в обоих видах.
  • Контекстное меню канала (ПКМ): "Program Guide", "Copy URL", "Copy Name", "Remove from playlist".
  • Полноэкранный режим видео (двойной клик, F или ESC).
  • Громкость, mute, задержка аудио, переключение аудио/субтитров (в меню).
