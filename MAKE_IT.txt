## Пошаговый план реализации улучшенного диалога добавления EPG-источника

---

### Шаг 1. Создать внешний HTML-файл с информацией об источниках
**Цель:** хранить список популярных EPG-источников в отдельном файле, чтобы легко обновлять без перекомпиляции.  
**Действие:**  
- Создать файл `resources/epg_sources.html` с таблицей источников (регион, название, URL, примечания).  
- Добавить базовый CSS для красивого отображения.  
- Включить файл в систему контроля версий.

---

### Шаг 2. Реализовать диалог информации об источниках (`EpgSourcesInfoDialog`)
**Цель:** показать окно с HTML-страницей, загруженной из внешнего файла.  
**Действие:**  
- Создать класс `EpgSourcesInfoDialog` (наследник `wxDialog`).  
- В конструкторе загрузить HTML-файл из каталога ресурсов (`wxStandardPaths::Get().GetResourcesDir()`).  
- Если файл не найден, показать встроенную заглушку.  
- Отобразить HTML через `wxHtmlWindow`.  
- Добавить кнопку OK для закрытия.

---

### Шаг 3. Реализовать основной диалог добавления источника (`AddEpgSourceDialog`)
**Цель:** предоставить простой интерфейс для ввода URL или выбора локального файла с автоматическим заполнением имени.  
**Действие:**  
- Создать класс `AddEpgSourceDialog` (наследник `wxDialog`).  
- UI:  
  - Информационная строка + кнопка "More info about popular sources →" (открывает `EpgSourcesInfoDialog`).  
  - Поле "URL / Path" (`wxTextCtrl`) с кнопкой "Browse..." (`wxButton`).  
  - Поле "Name (optional)" (`wxTextCtrl`) с подсказкой об автозаполнении.  
  - Кнопки OK/Cancel.  
- Логика:  
  - При вводе текста в поле URL/пути или выборе файла через Browse – автоматически заполнять поле "Name", если оно пустое.  
  - При нажатии OK – валидировать:  
    * Поле не пустое.  
    * Если значение не начинается с `http://` или `https://`, проверить существование файла.  
  - Возвращать через методы: `GetUrlOrPath()`, `GetName()`, `IsFileSource()`.

---

### Шаг 4. Обновить `EPGPanel::OnManageSources`
**Цель:** заменить вызов `SettingsDialog` на новый диалог и интегрировать добавление источника в `EPGManager`.  
**Действие:**  
- В `EPGPanel::OnManageSources`:  
  1. Создать `AddEpgSourceDialog`.  
  2. Если пользователь нажал OK – получить URL/путь и имя.  
  3. Если имя пустое – сгенерировать его (дублируем логику автозаполнения из диалога).  
  4. Проверить дубликат по `url` в `EPGManager::GetSources()`.  
  5. Добавить источник (`EpgSource`) в список и сохранить через `SetSources()`.  
  6. Загрузить EPG через `LoadFromUrl()` или `LoadFromFile()` в зависимости от типа.  
  7. Обновить статус через `SetStatus()`.

---

### Шаг 5. Добавить метод `LoadFromFile` в `EPGManager`
**Цель:** поддержка загрузки EPG из локального XMLTV-файла.  
**Действие:**  
- В `EPGManager.h` объявить `bool LoadFromFile(const std::string& filePath);`.  
- В `EPGManager.cpp` реализовать:  
  - Открыть файл в бинарном режиме.  
  - Прочитать содержимое в строку.  
  - Передать строку в `ParseAndMerge()` с источником `"file://" + filePath`.  
  - Обработать ошибки (файл не найден, не читается).

---

### Шаг 6. Настроить сборку и инсталляцию для `epg_sources.html`
**Цель:** обеспечить копирование HTML-файла в каталог ресурсов при сборке и установке.  
**Действие:**  
- В `CMakeLists.txt` (или системе сборки):  
  - Добавить команду `configure_file` для копирования в каталог сборки (для отладки).  
  - Добавить `install(FILES ...)` для копирования в системный каталог (Linux) или в папку с приложением (Windows).  
- В установщике (Inno Setup, NSIS) включить `epg_sources.html` в список файлов для копирования.  
- Убедиться, что в коде `wxStandardPaths::Get().GetResourcesDir()` возвращает корректный путь на всех платформах.

---

### Шаг 7. Тестирование и отладка
**Цель:** проверить все сценарии работы диалога.  
**Действие:**  
- Добавление URL-источника – EPG загружается и отображается в панели.  
- Добавление локального файла – загрузка работает.  
- Кнопка "More info" – открывается окно с таблицей (если файл есть) или заглушкой.  
- Автозаполнение имени – работает для URL и файлов.  
- Валидация – не даёт добавить пустое поле или несуществующий файл.  
- Дубликаты – блокируются.

---

### Шаг 8. Документация
**Цель:** описать изменения для пользователей и разработчиков.  
**Действие:**  
- Добавить в `README.md` раздел о настройке EPG-источников.  
- Обновить `CHANGELOG.md` с описанием нового функционала.  
- При необходимости добавить комментарии в коде для новых классов и методов.

---

### Результат
После реализации всех шагов пользователь получит:
- Простой диалог для добавления EPG-источников (URL или файл).  
- Информационное окно с актуальным списком популярных источников (из внешнего HTML).  
- Возможность загружать локальные XMLTV-файлы.  
- Автоматическое заполнение имени для удобства.
