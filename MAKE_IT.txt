## Точный пошаговый план реализации (без кода)

### Часть 1. Улучшение алгоритма матчинга

**Файлы:** `EPGManager.h`, `EPGManager.cpp`  
**Метод:** `EPGManager::FindBestMatch`

1. **Перестроить логику выбора**  
   - Создать структуру `Candidate { std::string epgId; int score; std::string method; }`.  
   - Для каждого EPG-канала из `m_normalizedCache` вычислить **максимальный балл** по всем методам (кроме ручного).  
   - Ручное сопоставление (из `m_manualMapping`) проверять **в первую очередь** – если найдено, сразу возвращать его с баллом 100.  
   - Для остальных методов:
     - **Точное совпадение** (нормализованные имена равны) → балл 100.
     - **Token sort** (наборы токенов совпадают после сортировки) → балл 85.
     - **Fuzzy** (расстояние Левенштейна) → балл = `similarity` (0–100), если `similarity >= m_fuzzyThreshold` (по умолчанию 75).
     - **Substring** → балл = 50 (или `similarity`, если подстрока составляет >= `m_substringMinRatio`% от длины обоих имён и длина имени >= `m_substringMinLength`).
     - **Exact tvg-id** (если `tvgId` не пуст и совпадает после нормализации) → балл 70.
   - Для каждого EPG-канала сохранить **максимальный** балл из всех методов (и метод, которым он достигнут).  
   - После обхода всех EPG-каналов выбрать кандидата с **наибольшим баллом**. Если балл >= `m_minMatchScore` (по умолчанию 50), вернуть его; иначе вернуть пустой результат.

2. **Добавить приватные переменные-члены** в `EPGManager`:
   - `int m_fuzzyThreshold = 75;`
   - `int m_substringMinLength = 6;`
   - `int m_substringMinRatio = 30;`
   - `int m_minMatchScore = 50;`
   - Метод `void LoadMatchSettings()` для чтения из `ConfigManager`.

3. **Загружать настройки** в конструкторе или при открытии БД.

4. **Добавить логирование** – в `FindBestMatch` перед возвратом выводить через `LOG_DEBUG` имя канала плейлиста, выбранный EPG-канал, метод и балл.

### Часть 2. Настройка порогов через ConfigManager

**Файлы:** `ConfigManager.h` (уже есть `getInt`/`setInt`), **не требует изменений**.  
Использовать ключи:
- `"epg_fuzzy_threshold"` (int, default 75)
- `"epg_substring_min_length"` (int, default 6)
- `"epg_substring_min_ratio"` (int, default 30)
- `"epg_min_match_score"` (int, default 50)

В `EPGManager::LoadMatchSettings` читать эти значения через `m_configManager->getInt(...)`.

### Часть 3. Интерфейс для изменения порогов в `EpgSourceManagerPanel`

**Файлы:** `EpgSourceManagerPanel.h`, `.cpp`

1. **Добавить элементы управления** в существующую секцию "Auto-update settings" (или создать новую "Match settings"):
   - `wxSpinCtrl *m_fuzzyThresholdSpin` (диапазон 50–100)
   - `wxSpinCtrl *m_substringMinLengthSpin` (1–20)
   - `wxSpinCtrl *m_substringMinRatioSpin` (1–100)
   - `wxSpinCtrl *m_minScoreSpin` (1–100)

2. **В `LoadSettings()`** – прочитать текущие значения через `m_epgMgr->Get...()` (или напрямую из ConfigManager) и установить в спин-контролы.

3. **В `SaveSettings()`** – сохранить значения через `m_epgMgr->Set...` (с обновлением внутренних переменных) и вызвать `m_configManager->setInt` для каждого ключа.

4. **После сохранения** – если плейлист активен, предложить пересчитать маппинг (кнопка "Re-match" или автоматически). Для этого в `EPGManager` можно добавить метод `ReMatchCurrentPlaylist()`, который вызовет `MatchChannels` для текущего плейлиста.

### Часть 4. Ручной маппинг через UI (новая возможность)

**Файлы:** Создать новый диалог `ManualMappingDialog` (`.h`, `.cpp`).

1. **Диалог** содержит:
   - Список каналов из текущего плейлиста (имя, tvg-id) – передаётся извне.
   - Список всех EPG-каналов (из БД) – получается через `EPGManager::GetAllChannels()`.
   - Кнопка "Add mapping" – связывает выбранный канал плейлиста с выбранным EPG-каналом.
   - Список уже существующих ручных маппингов для текущего плейлиста (с возможностью удаления).

2. **Логика:**
   - При добавлении вызывается `EPGManager::SetManualMapping(tvgId, epgId)`.
   - При удалении – `EPGManager::RemoveChannelMapping(tvgId)`.
   - После изменения обновить список маппингов в диалоге.

3. **Место вызова:**  
   - Добавить кнопку "Manual Mapping..." на панели `EpgSourceManagerPanel` (рядом с "Add", "Edit" и т.д.).  
   - При нажатии открывать диалог, передавая в него текущий список каналов (из `MainFrame` или `PlaylistManager`).

4. **В `EPGManager` добавить** (если отсутствует):
   - `std::vector<std::pair<std::string, std::string>> GetAllEpgChannels()` – обёртка над `EPGDatabase::GetAllChannels()`.
   - `std::vector<Channel> GetCurrentPlaylistChannels()` – если не передаётся извне, можно запросить у `PlaylistManager`.

- Включить `LOG_DEBUG` для матчинга (уровень логирования должен позволять).

### Дополнительные рекомендации

- В `FindBestMatch` при сравнении имён используйте **нормализованные** строки, полученные через `NormalizeName`.  
- Убедитесь, что `m_normalizedCache` заполняется **всеми** каналами из БД (метод `RebuildNormalizedCache` вызывается перед матчингом).  
- Для повышения производительности можно кэшировать вычисленные баллы для часто используемых каналов, но на объёмах до 10–20 тысяч каналов это не критично.

Этот план покрывает все требуемые изменения: улучшение алгоритма, настройку порогов через UI и конфиг, ручной маппинг через интерфейс. Все изменения локализованы, не затрагивают архитектуру приложения и могут быть реализованы последовательно.
