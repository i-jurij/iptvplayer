# 🎯 Что именно создаёт полоски (и почему Fix #3 был неверен)

Полоски шириной ~5px справа, слева и снизу в fullscreen появляются из двух источников:

### 1️⃣ **Splitter создаёт рамку и sash даже когда UI скрыт**
Ты используешь:

```cpp
wxSP_LIVE_UPDATE | wxSP_3D
```

`wxSP_3D` → рисует **3D‑бордюр** вокруг обеих панелей.  
В fullscreen этот бордюр превращается в **полоски слева/справа**.

Даже если временный плейлист скрыт, splitter всё равно рисует:

- внешнюю рамку,
- внутреннюю рамку,
- sash (разделитель).

### 2️⃣ **mainPanel имеет минимальный размер, который не исчезает при скрытии UI**
Когда ты скрываешь:

- headerPanel  
- controlsPanel  
- progressPanel  

они исчезают, но **mainPanel остаётся**, и его sizer всё равно резервирует несколько пикселей снизу → **нижняя полоска**.

---

# ❌ Почему Fix #3 (ReplaceWindow) был неверен

Ты прав: fullscreen у тебя не “чистый” — UI должен возвращаться при движении мыши.  
Если заменить layout, то:

- временный плейлист исчезнет из splitter-а,
- при движении мыши его уже некуда показать,
- поведение нарушится.

Поэтому **layout менять нельзя**.

# ⭐ Идеальный минимальный фикс (канвас не трогаем)

## ✔ Решение состоит из двух частей:

---

# ✅ Fix A — убрать рамку splitter-а только в fullscreen

Это полностью убирает полоски слева и справа.

В `ToggleFullscreen()`:

```cpp
if (m_isFullscreen) {
    m_splitter->SetWindowStyleFlag(wxSP_LIVE_UPDATE | wxSP_NO_BORDER);

    // если твоя версия wxWidgets поддерживает:
    // m_splitter->SetSashInvisible(true);

} else {
    m_splitter->SetWindowStyleFlag(wxSP_LIVE_UPDATE | wxSP_3D);

    // m_splitter->SetSashInvisible(false);
}
```

### ✔ Это НЕ ломает:
- восстановление UI,
- временный плейлист,
- работу sash-а,
- перетаскивание границы,
- layout.

### ✔ Это убирает:
- левую полоску,
- правую полоску.

---

# ✅ Fix B — убрать нижнюю полоску, не трогая канвас и layout

Когда UI скрыт в fullscreen, `mainPanel` остаётся, и его sizer держит минимальную высоту.  
Нужно временно убрать минимальный размер.

В `SetControlsVisible()` добавь:

```cpp
if (m_isFullscreen && !show && m_mainPanel) {
    // скрываем UI → убираем минимальный размер
    m_mainPanel->GetSizer()->SetMinSize(wxSize(0, 0));
}

if (m_isFullscreen && show && m_mainPanel) {
    // показываем UI → возвращаем минимальный размер
    m_mainPanel->GetSizer()->SetMinSize(wxDefaultSize);
}
```

### ✔ Это НЕ ломает:
- восстановление UI,
- временный плейлист,
- layout,
- канвас.

### ✔ Это убирает:
- нижнюю полоску.
