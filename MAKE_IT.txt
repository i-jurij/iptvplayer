## Поддержка gzip и ZIP-распаковки в EPGManager без внешних зависимостей

**Краткий ответ:**
- **zlib** есть во всех основных системах (Linux, macOS, Windows) и уже используется в wxWidgets.
- **ZIP** будем распаковывать через **встроенный `wxZipInputStream`** (из wxWidgets), который работает с памятью через `wxMemoryInputStream`.

---

### Изменения в `EPGManager.cpp`

#### 1. Добавить необходимые заголовки

```cpp
#include <wx/zipstrm.h>
#include <wx/mstream.h>
#include <wx/wfstream.h>
#include <wx/zlib.h>   // для gzip (если использовать wxZlibInputStream)
#include <zlib.h>      // для ручной распаковки gzip (альтернатива)
```

Мы будем использовать **wxZlibInputStream** для gzip и **wxZipInputStream** для ZIP — они встроены в wxWidgets и не требуют отдельной линковки (кроме стандартных компонентов wxWidgets).

#### 2. Вспомогательная функция распаковки

```cpp
static bool DecompressGzip(const std::string& compressed, std::string& decompressed) {
    wxMemoryInputStream memIn(compressed.data(), compressed.size());
    wxZlibInputStream zlibIn(memIn);
    if (!zlibIn.IsOk()) {
        return false;
    }
    wxStringOutputStream out;
    zlibIn.Read(out);
    if (zlibIn.GetLastError() != wxSTREAM_NO_ERROR) {
        return false;
    }
    decompressed = out.GetString().ToStdString();
    return true;
}

static bool DecompressZip(const std::string& compressed, std::string& decompressed) {
    wxMemoryInputStream memIn(compressed.data(), compressed.size());
    wxZipInputStream zipIn(memIn);
    if (!zipIn.IsOk()) {
        return false;
    }

    // Ищем первый файл в архиве (обычно это единственный XML)
    std::unique_ptr<wxZipEntry> entry(zipIn.GetNextEntry());
    if (!entry || entry->IsDir()) {
        return false;
    }

    wxStringOutputStream out;
    zipIn.Read(out);
    if (zipIn.GetLastError() != wxSTREAM_NO_ERROR) {
        return false;
    }
    decompressed = out.GetString().ToStdString();
    return true;
}
```

#### 3. Изменить `LoadFromUrl` (добавить автоопределение формата)

```cpp
bool EPGManager::LoadFromUrl(const std::string &url, const std::string &userAgent) {
    if (!m_playlistManager) {
        setLastError("PlaylistManager is null");
        LOG_ERROR("EPGManager: PlaylistManager is null");
        return false;
    }

    std::string xmlData;
    ErrorCode ec = m_playlistManager->downloadUrl(url, xmlData, userAgent);
    if (ec != ErrorCode::OK) {
        setLastError("Failed to download EPG from " + url + ": " +
                     m_playlistManager->getLastError());
        LOG_ERROR("EPGManager: Failed to download EPG from %s", url.c_str());
        return false;
    }

    // Определяем тип сжатия по магическим байтам
    bool isGzip = (xmlData.size() >= 2 &&
                   static_cast<unsigned char>(xmlData[0]) == 0x1F &&
                   static_cast<unsigned char>(xmlData[1]) == 0x8B);

    bool isZip = (xmlData.size() >= 4 &&
                  static_cast<unsigned char>(xmlData[0]) == 0x50 &&
                  static_cast<unsigned char>(xmlData[1]) == 0x4B &&
                  static_cast<unsigned char>(xmlData[2]) == 0x03 &&
                  static_cast<unsigned char>(xmlData[3]) == 0x04);

    if (isGzip) {
        std::string decompressed;
        if (DecompressGzip(xmlData, decompressed)) {
            LOG_DEBUG("EPGManager: Decompressed gzip (%zu -> %zu bytes)",
                      xmlData.size(), decompressed.size());
            xmlData.swap(decompressed);
        } else {
            setLastError("Failed to decompress gzip data from " + url);
            LOG_ERROR("EPGManager: Failed to decompress gzip from %s", url.c_str());
            return false;
        }
    } else if (isZip) {
        std::string decompressed;
        if (DecompressZip(xmlData, decompressed)) {
            LOG_DEBUG("EPGManager: Decompressed zip (%zu -> %zu bytes)",
                      xmlData.size(), decompressed.size());
            xmlData.swap(decompressed);
        } else {
            setLastError("Failed to decompress zip data from " + url);
            LOG_ERROR("EPGManager: Failed to decompress zip from %s", url.c_str());
            return false;
        }
    }

    return ParseAndMerge(xmlData, url);
}
```

---

### Что изменилось

- **Поддержка ZIP** через `wxZipInputStream` (без внешних утилит).
- **Поддержка gzip** через `wxZlibInputStream` (тоже встроен).
- **Автоопределение** формата по магическим байтам.
- **Отсутствие внешних зависимостей** (кроме стандартного wxWidgets, который уже подключён).

---

### Почему это безопасно

- `wxZipInputStream` читает только первый файл в архиве (обычно это и есть XMLTV).
- При ошибках распаковки возвращается `false`, логируется ошибка.
- Если данные не сжаты, они передаются в `ParseAndMerge` без изменений.

Теперь программа сможет загружать как `.xml`, так и `.xml.gz`, и `.zip` EPG-источники. Включая финскую ссылку, которую вы упомянули.
