### Шаг 1. Добавление уникального идентификатора плейлиста
**Цель:** каждый плейлист должен иметь стабильный ID для привязки mapping.

2. В конструкторах генерировать ID (например, через `wxUuid::Create().ToString().ToStdString()` или случайную строку).
3. В `toJson()` и `fromJson()` сохранять/загружать поле `uniqueId`.
4. При загрузке плейлистов (в `PlaylistManager::loadPlaylists()`), если у плейлиста нет ID – сгенерировать и вызвать `savePlaylist()` для этого плейлиста (чтобы обновить файл).
5. В `MainFrame::loadPlaylistChannels` получать ID через `playlist->getUniqueId()` и передавать его в EPGManager (добавить параметр в метод).

### Шаг 2. Создание класса `EPGDatabase` (SQLite)
**Цель:** хранить каналы, программы и mapping в SQLite.

**Новые файлы:** `EPGDatabase.h`, `EPGDatabase.cpp`

1. Подключить SQLite3 (заголовочный файл и библиотеку).
2. В `EPGDatabase` реализовать:
   - `bool Open(const std::string& dbPath)` – открывает или создаёт БД.
   - `void Close()`.
   - `bool CreateTables()` – создаёт таблицы:
     - `channels` (id TEXT PRIMARY KEY, display_name TEXT)
     - `programs` (id INTEGER PRIMARY KEY, channel_id TEXT, start_time INTEGER, stop_time INTEGER, title TEXT, description TEXT, category TEXT) – уникальный индекс `(channel_id, start_time)`.
     - `playlist_metadata` (playlist_id TEXT PRIMARY KEY, channel_count INTEGER, channel_hash TEXT, epg_hash_at_match TEXT, last_match_time INTEGER)
     - `playlist_mappings` (playlist_id TEXT, key TEXT, channel_id TEXT, is_manual INTEGER DEFAULT 0, confidence TEXT, PRIMARY KEY (playlist_id, key))
   - `BeginTransaction()`, `Commit()`, `Rollback()`.
   - `InsertOrUpdateChannel(const EpgChannel&)`.
   - `InsertProgram(channelId, program)` – с проверкой дубликата по `(channel_id, start_time)`.
   - `InsertPrograms(channelId, programs)` – массовая вставка с транзакцией.
   - `GetProgramsForChannel(channelId, start, end)`.
   - `GetCurrentProgram(channelId, now)`.
   - `DeleteProgramsOlderThan(threshold)`.
   - `ClearChannelPrograms(channelId)`.
   - `SavePlaylistMapping(playlistId, mapping, manualMapping, channelCount, channelHash, epgHash)` – удаляет старые записи для playlistId и вставляет новые.
   - `LoadPlaylistMapping(playlistId, mapping, manualMapping, channelCount, channelHash, epgHashAtMatch)` – загружает данные.
   - `GetMappingEntry(playlistId, key, channelId, isManual)` – для проверки ручных маппингов.
   - `DeletePlaylistMapping(playlistId)`.
   - `GetEpgChannelsHash()` – вычисляет хеш списка каналов EPG (из `SELECT DISTINCT channel_id FROM programs ORDER BY channel_id` и SHA-256/CRC).
3. В `Open` проверить, есть ли таблицы; если нет – вызвать `CreateTables()`.
4. Добавить обработку ошибок и логирование.

  }
