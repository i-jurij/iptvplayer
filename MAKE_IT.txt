## Пункт 1. Управление фоновыми задачами (EPG Refresh, добавление из URL)
- **Проблема**: `std::thread` в `EPGManager::Refresh` и `PlaylistManager::addPlaylistFromUrl` не сохраняются, при закрытии приложения потоки могут обращаться к разрушенным объектам.
- **Решение**:
  - Заменить `std::thread` на `std::async` с сохранением `std::future`.
  - Добавить методы `WaitForRefresh()` и `WaitForAddFromUrl()` с таймаутом 5 секунд.
  - В деструкторе `MainFrame` и в `onQuit` вызывать эти методы.
  - Добавить мьютекс для `m_lastError` в обоих менеджерах.
  - Убрать `rawPtr` в `addPlaylistFromUrl`, использовать `unique_ptr` до перемещения в вектор.
- **Изменения**: ранее описаны полностью.

## Пункт 2. Сохранение EPG-сопоставления (mapping) после MatchChannels
- **Проблема**: `EPGManager::MatchChannels` обновляет `m_channelMapping`, но не вызывает `SaveToCache()`, поэтому сопоставления теряются после перезапуска.
- **Решение**: В конце `MatchChannels` добавить вызов `SaveToCache()` (вне мьютекса, чтобы не блокировать).
- **Код**:
```cpp
void EPGManager::MatchChannels(const std::vector<Channel> &playlistChannels) {
    {
        std::lock_guard<std::mutex> lock(m_mutex);
        m_channelMapping.clear();
        for (const auto &ch : playlistChannels) {
            std::string tvgId = ch.getTvgId();
            if (tvgId.empty()) continue;
            auto it = m_channels.find(tvgId);
            if (it != m_channels.end()) {
                m_channelMapping[tvgId] = tvgId;
            }
        }
        LOG_DEBUG("EPGManager: Matched %zu channels", m_channelMapping.size());
    }
    SaveToCache(); // <-- добавить
}
```

## Пункт 4. Обновление UI при удалении канала (EPG, избранное, видео)
- **Проблема**: При удалении канала из плейлиста (`RemoveChannelFromPlaylist`) фоново удаляются логотипы, EPG-маппинг и избранное, но UI EPG-панели и избранного не обновляются, и если канал воспроизводится — не останавливается.
- **Решение**:
  - После удаления из избранного отправить событие обновления избранного (или вызвать `refreshFavorites` в UI-потоке).
  - Для EPG-панели обновить текущую программу, если этот канал выбран.
  - Если удаляемый канал сейчас воспроизводится, остановить воспроизведение.
- **Код** (в `MainFrame::RemoveChannelFromPlaylist` после фонового удаления из избранного и EPG, добавить в лямбду или CallAfter):
```cpp
// В конце фоновой задачи, после удаления из избранного и EPG:
wxTheApp->CallAfter([this, chNameBg, playlistName]() {
    // Обновить список избранного
    refreshFavorites();
    // Если EPG-панель открыта и показывает этот канал, перезагрузить
    if (m_epgPanel && m_epgPanel->GetCurrentChannelId() == chNameBg) {
        m_epgPanel->LoadProgramsForChannel(chNameBg, time(nullptr));
    }
    // Если видео плеер воспроизводит этот канал, остановить
    if (m_videoPanel && m_videoPanel->GetCurrentChannelName() == chNameBg) {
        m_videoPanel->Stop();
    }
});
```

## Пункт 5. Обработка ошибок при загрузке EPG-кэша (очистка данных при битом JSON)
- **Проблема**: В `EPGManager::LoadFromCache` при ошибке парсинга данные остаются от предыдущего состояния, что приводит к неконсистентности.
- **Решение**: В случае любой ошибки (невалидный JSON, отсутствие полей) очищать `m_channels`, `m_channelMapping` и устанавливать `m_loaded = false`.
- **Код** (в `LoadFromCache`, после проверки ошибок):
```cpp
if (doc.Parse(json.c_str()).HasParseError() || !doc.IsObject()) {
    LOG_ERROR("EPGManager: Failed to parse cache JSON");
    std::lock_guard<std::mutex> lock(m_mutex);
    m_channels.clear();
    m_channelMapping.clear();
    m_loaded = false;
    return false;
}
// ... далее при отсутствии обязательных полей также очищать и возвращать false
```

## Пункт 8. Производительность: возврат константных ссылок в EPGManager
- **Проблема**: `GetProgramsForChannel` возвращает `std::vector<EpgProgram>` по значению, создавая копии. При больших плейлистах это дорого.
- **Решение**: Изменить сигнатуру на `const std::vector<EpgProgram>& GetProgramsForChannel(...) const` (но нужно хранить результаты в кэше или возвращать по ссылке на внутренние данные). Однако текущая реализация собирает результат в локальный вектор, поэтому ссылку вернуть нельзя. Альтернатива: возвращать `std::span` или итераторы, но проще оставить как есть, но добавить перемещение (C++17 RVO). Можно также добавить метод, возвращающий `std::vector<EpgProgram>` с `std::move`. В данном случае оставим без изменений, но учтём.

## Пункт 9. Согласованность настроек логотипов (ApplyChannelsNoLogoToViews)
- **Проблема**: Флаг `m_channelsNoLogo` используется в нескольких местах, но методы `SetShowLogoFromSettings` и `ApplyChannelsNoLogoToViews` не реализованы или не вызываются при изменении настроек.
- **Решение**: Реализовать `ApplyChannelsNoLogoToViews`, который обновляет `ChannelList` и `ChannelCards` (перерисовывает), и вызывать его при изменении настроек через `SettingsDialog` и при переключении кнопки логотипа.
- **Код**:
```cpp
void MainFrame::ApplyChannelsNoLogoToViews() {
    if (m_channelList) {
        m_channelList->SetShowLogos(!m_channelsNoLogo);
        m_channelList->Refresh();
    }
    if (m_channelCards) {
        m_channelCards->SetShowLogos(!m_channelsNoLogo);
        m_channelCards->RefreshCards();
    }
    if (m_favList) {
        m_favList->SetShowLogos(!m_channelsNoLogo);
        m_favList->Refresh();
    }
    if (m_favCards) {
        m_favCards->SetShowLogos(!m_channelsNoLogo);
        m_favCards->RefreshCards();
    }
}
```
Вызывать после изменения `m_channelsNoLogo` (в обработчике кнопки и после загрузки настроек).

## Пункт 11. Обработка исключений в потоках
- **Проблема**: В лямбда-задачах (например, в `std::async` в `RemoveChannelFromPlaylist`) исключения не обрабатываются.
- **Решение**: Обернуть тело каждой фоновой задачи в `try-catch` и логировать ошибку.
- **Код** (пример для лямбды в `RemoveChannelFromPlaylist`):
```cpp
m_backgroundTasks.push_back(std::async(std::launch::async, [/*...*/]() {
    try {
        // ... код ...
    } catch (const std::exception& e) {
        LOG_ERROR("RemoveChannelFromPlaylist[bg] exception: %s", e.what());
    } catch (...) {
        LOG_ERROR("RemoveChannelFromPlaylist[bg] unknown exception");
    }
}));
```
