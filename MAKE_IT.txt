### 2.2. `UpdateMatchProgress` — новый метод

Добавить рядом:

```cpp
void EPGManager::UpdateMatchProgress(bool isFavorites, int processed,
                                     int matched, int total, bool finished) {
  EpgProgressInfo info;
  {
    std::lock_guard<std::mutex> lock(m_matchAggMutex);
    if (isFavorites) {
      m_matchAgg.processedFav = processed;
      m_matchAgg.totalFav     = total;
      m_matchAgg.matchedFav   = matched;
    } else {
      m_matchAgg.processedCh  = processed;
      m_matchAgg.totalCh      = total;
      m_matchAgg.matchedCh    = matched;
    }

    int sumProcessed = m_matchAgg.processedCh + m_matchAgg.processedFav;
    int sumTotal     = m_matchAgg.totalCh     + m_matchAgg.totalFav;

    info.percent          = (sumTotal > 0) ? (sumProcessed * 100) / sumTotal : -1;
    info.matched          = m_matchAgg.matchedCh;
    info.totalChannels    = m_matchAgg.totalCh;
    info.favoritesMatched = m_matchAgg.matchedFav;
    info.favoritesTotal   = m_matchAgg.totalFav;
  }

  if (finished) {
    int remaining = m_activeMatchings.fetch_sub(1) - 1;
    info.stage = (remaining <= 0) ? EpgProgressStage::Done
                                  : EpgProgressStage::Matching;
  } else {
    info.stage = EpgProgressStage::Matching;
  }

  info.stageText = (info.stage == EpgProgressStage::Done)
                       ? std::string(_("Done").ToUTF8().data())
                       : std::string(_("Matching").ToUTF8().data());

  UpdateProgress(info);
}
```

## 6. Чек-лист после сборки

1. `Match Now` с загруженным плейлистом → **один** `Done`, статус `EPG Matching Done` + `Channels X/Y, Favorites A/B`. Гейдж идёт по взвешенному проценту, индикатор активности не пропадает до конца.
2. `Match Now` без плейлиста → **один** `Done`, `Favorites A/B` без `Channels`.
3. `Add`/`Refresh Now` при загруженном плейлисте → `Downloading`→`Extracting`→`Parsing`→`Matching`(оба)→**один** `Done`.
4. `Add`/`Refresh Now` без плейлиста → `Downloading`→…→`Parsing`→**один** `Done`.
5. `Delete Cache + Update All` без плейлиста → busy сбрасывается (шаг 2.23).
6. `Cancel` во время матчинга → busy сбрасывается, отменяются **оба** (шаг 1.3).
7. Повторный `Match Now` во время работы → `m_activeMatchings` не течёт, `Done` приходит один раз.
8. Плейлист без избранного / избранное без плейлиста → `Done` один раз.
9. `Downloading`/`Parsing`/`Extracting` визуально не изменились.
