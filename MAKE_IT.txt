## Детализированный пошаговый план улучшения EPG-модуля

### Предварительные замечания
- **Версия wxWidgets:** предполагается 3.2+ (с поддержкой SQLite через `wxSQLite3` или встроенный SQLite)
- **Совместимость:** изменения должны быть обратно совместимы с существующими файлами конфигурации
- **Тестирование:** после каждого этапа необходимо проводить регрессионное тестирование на реальных XMLTV-файлах и M3U-плейлистах
- **Логирование:** добавить детальное логирование в ключевых точках

## Этап 1: Миграция на SQLite

### Шаг 1.1: Добавить зависимость от SQLite

**Файлы:** `CMakeLists.txt` или файл проекта (`.vcxproj`)

- Добавить библиотеку SQLite3 в зависимости проекта
- Для wxWidgets можно использовать `wxSQLite3` (обёртка) или прямой вызов SQLite C API
- **Рекомендация:** использовать прямой SQLite C API (минимальный размер, максимальная производительность)

**Проверка:** Сборка проекта должна проходить без ошибок.

### Шаг 1.2: Создать класс `EPGDatabase`

**Новые файлы:** `EPGDatabase.h`, `EPGDatabase.cpp`

**Методы класса:**

1. **Конструктор/деструктор:**
   - `EPGDatabase()`
   - `~EPGDatabase()`

2. **Управление подключением:**
   - `bool Open(const std::string& dbPath)` — открыть или создать БД
   - `void Close()` — закрыть соединение
   - `bool IsOpen() const`

3. **Инициализация схемы:**
   - `bool CreateTables()` — создать таблицы, если их нет
   - `bool MigrateFromJson(const std::string& jsonPath)` — импорт старого JSON-кэша

4. **Работа с каналами:**
   - `bool InsertOrUpdateChannel(const EpgChannel& channel)` — добавить/обновить канал
   - `std::vector<EpgChannel> GetAllChannels()` — получить все каналы

5. **Работа с программами:**
   - `bool InsertProgram(const std::string& channelId, const EpgProgram& program)` — добавить одну программу
   - `bool InsertPrograms(const std::string& channelId, const std::vector<EpgProgram>& programs)` — добавить список (инкрементально, только новые)
   - `std::vector<EpgProgram> GetProgramsForChannel(const std::string& channelId, time_t startTime, time_t endTime)` — получить программы за период
   - `EpgProgram GetCurrentProgram(const std::string& channelId, time_t now)` — получить текущую программу
   - `bool DeleteProgramsOlderThan(time_t threshold)` — удалить устаревшие программы
   - `bool ClearChannelPrograms(const std::string& channelId)` — очистить все программы канала (при перезагрузке источника)

6. **Сопоставления (маппинги):**
   - `bool SaveMapping(const std::string& key, const std::string& channelId, bool isManual = false, const std::string& confidence = "")` — сохранить сопоставление
   - `std::string GetMapping(const std::string& key) const` — получить channelId по ключу
   - `std::unordered_map<std::string, std::string> GetAllMappings() const` — получить все сопоставления
   - `bool DeleteMapping(const std::string& key)` — удалить сопоставление

7. **Транзакции:**
   - `void BeginTransaction()`
   - `void CommitTransaction()`
   - `void RollbackTransaction()`

**Реализация:**
- Использовать подготовленные запросы (`sqlite3_prepare_v2`)
- Весь доступ к БД оборачивать в `std::lock_guard<std::mutex>` внутри класса (один мьютекс на БД)
- При вставке программ проверять существование (по `channel_id` и `start_time`) и вставлять только новые
- Использовать `INSERT OR REPLACE` для каналов и `INSERT OR IGNORE` для программ (с уникальным составным ключом `(channel_id, start_time)`)

**Проверка:** Написать юнит-тесты для каждого метода с использованием временной БД в памяти (`file::memory:`).

### Шаг 1.3: Адаптировать `EPGManager` для работы с `EPGDatabase`

**Файлы:** `EPGManager.h`, `EPGManager.cpp`

1. **Добавить поле:**
   ```cpp
   std::unique_ptr<EPGDatabase> m_db;
   ```

2. **Изменить конструктор:**
   - Принимать путь к папке кэша
   - Создавать экземпляр `EPGDatabase` и открывать БД по пути `cache_dir/epg.db`
   - Вызывать `CreateTables()`
   - Попытаться импортировать старый JSON-кэш, если он существует и БД пуста

3. **Удалить поля:** `m_channels` (unordered_map), `m_normalizedCache` (они больше не нужны)

4. **Переработать методы:**

   - **`LoadFromCache()`** → заменить на открытие БД и проверку наличия данных
   - **`SaveToCache()`** → удалить (заменить на фиксацию транзакций в БД)
   - **`BuildCacheJson()`** → удалить
   - **`ParseAndMerge()`** → вместо сохранения в `m_channels` вызывать:
     - `m_db->BeginTransaction()`
     - Для каждого канала: `m_db->InsertOrUpdateChannel()`
     - Для каждой программы: `m_db->InsertProgram()`
     - `m_db->CommitTransaction()`
   - **`CleanExpiredPrograms()`** → вызывать `m_db->DeleteProgramsOlderThan()` с аргументом `now - m_daysToKeep * 86400`
   - **`GetProgramsForChannel()`** → вместо поиска в `m_channels` выполнять запрос к БД
   - **`GetCurrentProgram()`** → аналогично
   - **`GetChannelIdsWithEpg()`** → выполнять запрос `SELECT DISTINCT channel_id FROM programs`
   - **`MatchChannels()`** → сохранять результаты через `m_db->SaveMapping()`
   - **`FindBestMatch()`** → сначала проверять ручные маппинги через `m_db->GetMapping()`, затем авто-маппинг по имени (с использованием данных из БД)
   - **`RebuildNormalizedCache()`** → удалить (больше не нужен, так как все данные в БД; для сопоставления можно делать запросы прямо к БД)

5. **Удалить старые поля:**
   - `m_channelMapping`
   - `m_manualMapping`
   - `m_normalizedCache`

6. **Адаптировать методы работы с маппингами:**
   - `SetManualMapping()` → `m_db->SaveMapping(tvgId, epgId, true)`
   - `GetEpgChannelIdForTvgId()` → `m_db->GetMapping(tvgId)`

7. **Обновить метод `DeleteCache()`** → удалять файл `epg.db` и пересоздавать таблицы

8. **Изменить путь к кэшу:** теперь это будет путь к папке, внутри которой создаётся `epg.db`.

**Проверка:** 
- Запустить приложение с существующим JSON-кэшем — должна произойти автоматическая миграция
- Убедиться, что все EPG-данные отображаются корректно
- Проверить работу поиска и фильтрации

### Шаг 1.4: Инкрементальное обновление

**Файл:** `EPGManager.cpp` (метод `ParseAndMerge`)

## Этап 2: Потокобезопасность

### Шаг 2.1: Замена мьютексов

**Файл:** `EPGManager.h`

- Удалить `std::recursive_mutex m_mutex`
- Добавить три `std::shared_mutex`:
  - `mutable std::shared_mutex m_dbMutex` — для доступа к БД
  - `mutable std::shared_mutex m_sourcesMutex` — для `m_sources`
  - `mutable std::shared_mutex m_configMutex` — для конфигурации (если нужен)

**Файл:** `EPGManager.cpp`

- Везде, где был `std::lock_guard<std::recursive_mutex> lock(m_mutex)`, заменить на:
  - Для чтения: `std::shared_lock<std::shared_mutex> lock(m_dbMutex)`
  - Для записи: `std::unique_lock<std::shared_mutex> lock(m_dbMutex)`

- Для `m_sources` аналогично.

**Проверка:** Запустить приложение в режиме отладки, убедиться, что нет deadlock'ов. Можно добавить тесты с несколькими потоками (один читает, другой пишет).

- После загрузки всех источников проверить, был ли хотя бы один успешный. Если да — считать обновление успешным.
- Сохранять список ошибок (строка) для отображения пользователю.

**Примерная структура:**

```cpp
std::vector<std::string> errors;
bool anySuccess = false;

for (const auto& src : sources) {
    bool ok = LoadSource(src);
    if (ok) anySuccess = true;
    else errors.push_back(...);
}

if (anySuccess) {
    m_lastUpdate = time(nullptr);
    SaveToCache(); // теперь это фиксация транзакций
    // Колбэк с PARTIAL или OK
} else {
    // Колбэк с ERROR и текстом ошибок
}
```

### Шаг 4.2: Модифицировать парсер

**Файл:** `EPGParserExpat.cpp`

- В `OnStartElement` для `programme` добавить состояние для новых тегов (например, `STATE_SUB_TITLE`, `STATE_EPISODE`, `STATE_STAR_RATING`).
- В `OnEndElement` заполнять соответствующие поля `m_currentProgram`.

**Новые теги XMLTV, которые нужно обрабатывать (опционально):**
- `<sub-title>` → `subTitle`
- `<episode-num>` → `episodeNum` (атрибут `system` может быть "xmltv_ns", "onscreen" и др.)
- `<star-rating>` → `starRating` (текст внутри)
- `<credits>` → внутри могут быть `<actor>`, `<director>` → сохранять в вектор
- `<language>` → `language`
- `<original-title>` → `originalTitle`

### Шаг 4.3: Потоковая обработка (частичная)

**Файл:** `EPGManager.cpp` (метод `LoadFromUrl`) и `EPGParserExpat`

- Изменить `LoadFromUrl`, чтобы он не скачивал весь файл целиком, а передавал данные в парсер по мере получения.
- Для этого:
  1. В `PlaylistManager::downloadUrl` добавить возможность вызова колбэка для каждого чанка данных.
  2. В `EPGParserExpat` добавить методы:
     - `BeginParse()`
     - `ParseChunk(const std::string& chunk)`
     - `EndParse()`
  3. В `LoadFromUrl` при получении чанка вызывать `m_parser->ParseChunk(chunk)`.

**Важно:** XML-документ может быть разбит произвольно, поэтому парсер должен корректно обрабатывать частичные данные. Expat это поддерживает, если использовать `XML_Parse` с флагом `isFinal = false` для каждого чанка, а в конце `XML_Parse` с `isFinal = true`.

**Проверка:** Загрузить большой XMLTV-файл (например, 200 МБ) и убедиться, что память не растёт и процессор не перегружается.
